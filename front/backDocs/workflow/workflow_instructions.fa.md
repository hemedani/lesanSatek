# راهنمای جامع تست — فرانت‌اند لسان‌ساتک

این راهنما با مجموعه تست **دو سازمانی** فعلی `back/http/e2e.json` (**۴۱۲ ورودی**)
هماهنگ است و چرخه کامل خرید تا پرداخت، انبار، بودجه، حسابداری دوبل، دوره‌های
حسابداری و جداسازی داده بین **سازمان آلفا** و **سازمان بتا** را پوشش می‌دهد.

---

## پیش‌نیازها

### ۱. راه‌اندازی بک‌اند (Deno)

```bash
cd /Users/syd/work/sitak/lesanSatek/back
deno task bc-dev
```

پلی‌گراند: `http://localhost:1370/playground`

### ۲. راه‌اندازی فرانت‌اند (Next.js)

```bash
cd /Users/syd/work/sitak/lesanSatek/front
pnpm dev
```

برنامه: `http://localhost:3000`

### ۳. اجرا روی پایگاه داده خالی

اکشن `user.tempUser` فقط زمانی کار می‌کند که مجموعه کاربران **خالی** باشد. برای
اجرای تکرارپذیر از یک پایگاه داده اختصاصی استفاده کنید:

```bash
cd /Users/syd/work/sitak/lesanSatek/back
MONGO_DB=lesanSatek_e2e APP_PORT=1370 ENV=development deno run --allow-all mod.ts
```

سپس `back/http/e2e.json` را در اجراکننده مجموعه پلی‌گراند (یا ورودی‌به‌ورودی و
به‌ترتیب) اجرا کنید. مجموعه حالت‌مند است و باید از ابتدا تا انتها روی دیتابیس
تازه اجرا شود.

نتیجه مورد انتظار:

- **۳۶۹ ورودی موفق**
- **۴۳ شکست عمدی** (`iso-*`، `authz-*`، `neg-*`)
- **۰ شکست غیرمنتظره**

هر شکست عمدی فیلد `expectedFailure: { "message": ... }` دارد؛ بنابراین
اجراکننده E2E پلی‌گراند رد شدن با پیام مطابق را «موفق» می‌شمارد و در پنل
Expected Failures نشان می‌دهد. موفقیت غیرمنتظره یا پیام خطای متفاوت، شکست واقعی
است. اسکریپت `ignore-scripts/_run_e2e.py` نیز همین منطق تطبیق را اعمال می‌کند.
